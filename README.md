# Modèle Bounty — installeurs

Installeurs Windows des applications Modèle Bounty (SecIA) et manifestes de mise à jour automatique. Aucun code, aucune donnée.

Téléchargez la dernière version dans « Releases ». Installeurs non signés Windows : au premier lancement, cliquer « Informations complémentaires » puis « Exécuter quand même ». Les applications se mettent ensuite à jour toutes seules.
